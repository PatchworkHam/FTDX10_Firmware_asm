## 1. TS 的存储与选择

### 1.1 存储

`FRAM[0x0007]`：

```text
bit0-2  TS      （3 bit，0–7）
bit3-4  PWR     （功率档）
bit5    EXP     （宽频段表；优先级高于 TS）
bit6    AUX0    （本版未使用，恢复设置时强制清 0）
bit7    AUX1    （本版未使用）
```

RAM 镜像：`0xFF2007`。上电时由 FRAM 装入；改 FRAM 后需断电重启。

### 1.2 选择器：`0x32AEE–0x32B26`

```text
32aee: mov.l #0x32B4A,er2            ; 服务模式表
32af4: btst  #7,@0xFF2020
32af8: bne   0x32B26                 ; 服务模式 → 用 0x32B4A
32b00: mov.l #0x32B54,er2            ; EXP 表
32b06: btst  #5,@0xFF2007
32b0e: bne   0x32B26                 ; EXP=1 → 用 0x32B54
32b10: mov.b @0xFF2007,r2l
32b16: and.b #0x7,r2l                ; TS
32b18: shll.b #2,r2l
32b1e: mov.l @(0x32B2A:32,er2),er2   ; 8 项长字指针表
32b26: mov.w @er2+,r4                ; 第一字 = 段数
32b28: rts                           ; 返回 r4=段数, er2=段数组
```

优先级：**服务模式（`0xFF2020.7`）> EXP（`FRAM[0x0007].5`）> TS**。
EXP=1 会**整体替换** TS 表，不是叠加。

### 1.3 表格式

```text
u16 count
count × { u32 start_Hz, u32 end_Hz }     ; end = 实际上限 - 1
```

例：`0x001B7740–0x001E847F` = 1,800,000–1,999,999 Hz = 1.8–2.0 MHz。

消费函数 `0x32A76` → `0x336EA`（4 字节大端比较，含端点）：

- 当前频率落在某段 → `0x336EA` 返回 **carry set** → `0x32A76` 返回 **carry set** → `0x3D1F2` 执行 `bset #5`，即 **`0xFF2014.5 = 1`（在频段内）**
- 不在任何段 → carry clear → `0x3D1F2` 执行 `bclr #5`，即 **`0xFF2014.5 = 0`（越界）**
- 结果同时更新 `0xFF2358`（当前波段起点）、`0xFF236E`（索引）。

> 极性：`.5 = 1` 是“**在频段内**”，`.5 = 0` 是“**越界**”。

`0x32A76` 的调用者：`0x33350`（波段切换/显示）、`0x3D1F6`（经 `0x3D1F2` 包装）。
`0x3D1F2` 又从 `0x2BF18`（CAT 状态回包）、`0x3CAF8`（TX 启动后）和 TX 状态机 `0x3D0C2`（TX 许可门闩）调用。

## 5. 如何开启 5 MHz 发射

### 5.1 方案 A：改 TS（推荐，可逆）

| 需求 | TS | `FRAM[0x0007]` 低 3 位 | 覆盖 |
|---|---:|---:|---|
| 5 MHz 最宽 + 4 m | **2** | `0b010` | 5.25–5.4065 + 70–70.5 + 50–52 |
| 窄 60 m + 最宽 HF | **7** | `0b111` | 5.3515–5.3665 + 1.8–30 + 50–54 |
| 窄 60 m 保守 | **3** | `0b011` | 5.3515–5.3665 + 50–52 |

写法（只改 TS，保留 PWR/EXP/AUX）：

```text
new = (old & 0xF8) | ts
```

例：旧值 `0x08`，TS=2 → `new = 0x0A`。

> 若当前 EXP=1，TS 表会被 EXP 表整体替换；要让 TS 表生效，先清 bit5：
> `new = (old & 0xD8) | ts`。脚本默认 `--exp keep`，会保留当前 EXP 并打印警告；
> 要强制使用 TS 表，显式加 `--exp off`（例如 `--ts 2 --exp off --apply`）。

### 5.2 方案 B：EXP=1

```text
new = old | 0x20
```

得到 1.8–30 连续 + 50–54 + 70–70.5，包含 5 MHz。

注意：

- EXP 优先级高于 TS，设了 EXP 后 TS 表被忽略；
- 恢复/初始化设置的活路径 `0xA38`→`0xA58` 会用 **JP1006** 覆盖 bit5（`cfg = (cfg & 0x9F) | jumper.EXP`）。软改 bit5 在“恢复设置”后会被清掉；
- 想长期稳定，焊 **JP1006**；
- AUX0（bit6）在同一路径被强制清 0。

### 5.3 方案 C：服务模式（最大范围）

`0x32B4A` = 1.8–75 MHz。`0x1562` 设置 `0xFF2020.7`：

```text
1440: jsr @0x1562
1562: bset #7,@0xFF2020
156a: jsr @0x2680
```

**入口已确认（CAT）**：

```text
ZZPE001000;   → 0xFF2002 = 0 → 软复位 → 服务模式
ZZPE001001;   → 0xFF2002 = 1 → 软复位 → 初始化/恢复设置（ALL RESET）
```

原始字节（ASCII + `;`）：

```text
ZZPE001000; = 5A 5A 50 45 30 30 31 30 30 30 3B
ZZPE001001; = 5A 5A 50 45 30 30 31 30 30 31 3B
```

两条命令都**立即软复位、无 `A;` 回包**；串口会断开/重启。

> ⚠️ **`ZZPE001001;` 不是普通重启**：`0xFF2002=1` 会走 `0x1446` → `0x1570` → `0x8E50` → `0x7EA2` → `0x8074`，用默认表 `0x82A6` 重写 `FRAM[0x0300]` 的 400B 用户设置块，等价于 **ALL RESET**。只想退出服务模式时，用 RESET 菜单（`0xDCBA` 清 `0xFF2020.7`）或整机断电重启。

**服务模式副作用（已确认）**：

- `0xFFAB00` 是**服务菜单项目编号** `N`（0–0x125，FRAM `0x0344`）。`0x2680` 用 `N*10` 索引 `0x27A8` 的 10 字节**项目描述表**，并调用 `0xA0C2` **切换当前波段/模式**：
  - `0xFFAAC6` 低 4 位 = 项目波段号 `b3`（FRAM `0x030A`）；仅当 `b0.7=1` 时高 4 位也设为 `b3`（当前表无此项）。
  - `0xFF2070.7/.4`、`0xFF206F.1/.0`、`0xFF2071.1/.0`、`0xFF206C` 低 4 位、`0xFFAB23` 低 3 位。
  - `0xFF20B6` = 项目频段频率，**仅当 `b0.6=1`**（当前表只有 70 MHz 项，值为 70.25 MHz）。
  - 这些是 **RAM 改写**，`0x2680` 本身不写 FRAM。
- 并行标签表 `0x3324`（294 × 25 B）证明 `N` 是服务菜单项目号：`0x110–0x11A` = `FB GAIN 1.8…70`，`0x11B–0x125` = `CART LIMIT 1.8…70`。详见 [`../service_menu/README.md`](../service_menu/README.md)。
- 退出 `0xDCBA` 会：
  - `0x8EF0`：把 `0xFFA948` 的 **371 B 内部设置**写入 FRAM `0x000A`；
  - `0x932A`：把项目号 `0xFFAB00` 写入 FRAM `0x0344`；
  - `0x9338`：把子码 `0xFFAB02` 写入 FRAM `0x0346`；
  - `bclr #7,@0xFF2020`，刷新显示。
- **进服务模式本身不改 400 B 用户设置块**；退出时会保存 371 B 内部设置和项目号/子码。若在服务模式里改了项目号（隐藏 CAT `SPN`，或 `0x15C2` 的加减）或内部设置，退出后会持久化。**先备份 FRAM，尤其 `0x000A–0x017C`、`0x030A`、`0x0344`、`0x0346`。**

证据链：

```text
27dee: cmp.b #'P',@0xFF8A32    ; 参数 "PE0010xx"
...
27e36: cmp.b #0x8,r3l          ; 参数长度必须 8
27e44: jsr @0x282A6            ; 校验后两位是十进制数字 '0'..'9'
27e50: r1l = (@0xFF8A38 << 4) | (@0xFF8A39 & 0xF)
27e64: jsr @0x35B72            ; BCD → 二进制
27e68: cmp.w #2,r3 ; bcc ?     ; 只接受 0 或 1
27e70: mov.b r3l,@0xFF2002
27e76: jmp @0x6EE              ; 软复位（无回包）
```

软复位入口 `0x6EE` 会置 `0xFF2000.4`；启动任务 `0x1394` 在 `0x1412` 检查该位，然后：

```text
1424: r0l = @0xFF2002
142a: jsr @0x35A20             ; 2 项分派表
1438: bset #7,@0xFF2062        ; 0xFF2002==0 → 服务模式
1440: jsr @0x1562              ;   → bset #7,@0xFF2020
1446: jsr @0x1570              ; 0xFF2002==1 → 初始化/恢复设置（ALL RESET）
                               ;   → 0x8E50 → 0xA38（JP1006 覆盖 EXP）
                               ;   → 0x7EA2 → 0x8074（默认表重写 400B 用户设置）
```

注意：

- **冷启动不走这条检查**：复位向量 `0x0000` 指向 `0x754`，`0x754` 会 `bclr #4,@0xFF2000`；只有 `jmp @0x6EE` 的软复位才置 bit4。
- `ZZPE001000` 进入服务模式时**不经过** `0x1570`/`0xA38`，所以不会用 JP1006 覆盖 EXP。
- `ZZPE001001` 触发初始化/恢复设置时会经过 `0x1570` → `0x8E50` → `0xA38`，**会把 EXP 改回 JP1006 状态**；若软改了 EXP 且没焊 JP1006，执行后 EXP 会丢失。
- 同一条 `0x1570` 路径还会调用 `0x7EA2` → `0x8074`，从默认表 `0x82A6` 重写 `FRAM[0x0300]` 的 400B 用户设置块，并初始化频段栈/消息/按键表。**不要把 `ZZPE001001;` 当作“返回普通模式”。**
- 服务模式同时打开 `SPN`/`SPA*` 门控，并把功率路径 `0x3BBC6`/`0x3BCA0` 切到“服务模式不钳位”。
- 退出服务模式：用 RESET 菜单（`0xDC02` 的 `0xDCBA` 分支会 `bclr #7,@0xFF2020` 并保存设置）或整机断电重启；冷启动 `0x754` 不经过 `0x1424` 检查，也不会调用 `0x1562`。

## 6. 最大范围对比

| 方案 | 覆盖 | 5 m | 70 m | 50–54 | 30–50 / 54–70 |
|---|---|---|---|---|---|
| TS=2 | 1.81–29.7（有缺口）+ 5.25–5.4065 + 50–52 + 70–70.5 | ✅ | ✅ | 仅 50–52 | ❌ |
| TS=7 | 1.8–30（有缺口）+ 5.3515–5.3665 + 50–54 | 窄 | ❌ | ✅ | ❌ |
| EXP | 1.8–30 + 50–54 + 70–70.5 | ✅ | ✅ | ✅ | ❌ |
| 服务模式 | 1.8–75 连续 | ✅ | ✅ | ✅ | ✅ |
| 硬件实际能力（推测） | PA/LPF 通常 1.8–54（+70 变体；本分析未验证） | — | — | — | 75 MHz 只是表值 |

结论：

- 要 **5 MHz + 4 m**：TS=2；
- 要 **5 MHz + 最宽 HF/6 m**：TS=7；
- 要 **HF 更连续 + 5 m + 70 m**：EXP；
- 要 **1.8–75 全开**：服务模式（CAT `ZZPE001000;`，见 §5.3）。

## 7. 证据与置信度

### 7.1 已确认

- 选择器优先级、8 项指针表、表格式：`0x32AEE–0x32B26`、`0x32B2A`；
- 8 张表全部段边界（直接解析二进制）；
- 服务表 `0x32B4A` = 1.8–75；EXP 表 `0x32B54` = 1.8–30 / 50–54 / 70–70.5；
- 5 MHz 预设模板与 TS 的映射：`0x8522–0x857E`、`0x884E/0x8904/0x89BA/0x89C8`；
- `FRAM[0x0007]` 位定义、`0xA38/0xA58` 只刷新 bit5；
- `0xFF2014.5` **极性**：`1` = 在频段内，`0` = 越界（`0x3D1F2` 的 `bset/bclr` 与 `0x336EA` 的 carry）；
- **MAIN 侧 TX 硬门闩**：`0x3D0C2` 在 TX 状态机里直接检查 `0x3D1F2`，越界清 `0xFFFBA4.2`。

### 7.2 TX 硬门闩（已确认）

MAIN 侧的 TX 状态机由 `0xFF23C4` 选择，分派器 `0x35A20`，14 项表 `0x3C924`（`0x3C964/0x3CB60/0x3CBDE/...`）。关键路径：

```text
状态 4 0x3CC20
  3cc32: jsr @0x3D0C2            ; TX 许可检查
  3cc36: r0l = 5
  3cc38: mov.b r0l,@0xFF23C4     ; 下一状态

0x3D0C2:
  3d0c2: jsr @0x1F02             ; 0xFFA94B != 0xFF
  3d0c6: beq 0x3D19A             ; 失败 → 清 0xFFFBA4.2
  3d0ca: btst #6,@0xFF2016       ; TX 禁止位
  3d0d2: bne 0x3D19A
  3d0d6: btst #7,@0xFF200D       ; TX 进行中
  3d0de: beq 0x3D19A
  3d0e2: jsr @0x3D1F2            ; 频段表检查
  3d0e6: bcc 0x3D19A             ; 越界（carry clear）→ 清 0xFFFBA4.2
  ...
  3d190: bset #2,@0xFFFBA4       ; 在频段内且其余条件通过 → 置 TX 允许
  3d19a: bclr #2,@0xFFFBA4       ; 失败 → 清 TX 允许
```

`0x3D1F2` → `0x32A70` → `0x32A76` → `0x32AEE`（服务/EXP/TS 表）→ `0x336EA`（区间比较）。**越界时 `0x3D0C2` 清 `0xFFFBA4.2`**；该位被 TX 序列 `0x30128/0x302B8` 和 TX 功率/表头 `0x3B7E2` 使用（`0x3B7E2` 在 `.2=0` 时直接返回 0）。

另有状态 1 `0x3CB60` 的早期检查：

```text
3cb6a: jsr @0x3D1F2
3cb6e: bcc 0x3CB8A         ; 越界 → 跳过 0xFF2057.0 置位
3cb70: jsr @0x1F02
3cb74: beq 0x3CB8A
3cb76: jsr @0x3CB9C         ; 服务模式额外置 0xFFFF5A.7
3cb7a: bset #1,@0xFFFBA4
3cb82: bset #0,@0xFF2057    ; TX 活动标志
```

因此 **MAIN 侧存在以频段表为输入的 TX 硬门闩**：`TS=2/3/7` 把 5 MHz 放进表后，`0x3D0C2` 的 `0x3D0E6` 分支会通过，`0xFFFBA4.2` 保持置位；`TS=0/1/5/6` 或 EXP=0 时 5 MHz 越界，`.2` 被清。服务模式表 1.8–75 也通过。

### 7.3 未定

- `0xFFFBA4.2` 之后到 PA/LPF 的模拟链路（本镜像外/未标注）；
- 显示侧/SUB 侧是否还有第二道 TX 门；
- 5 MHz 的 LPF/BPF 是否真的按 60 m 切换（硬件能力）；
- TS=4/5/7 在“配置有效”检查里被排除后的实际行为（表可被选中，但 `0x1502` 不置 `0xFF204A.7`）。

## 8. `FRAM[0x03FE]`：发射超时（TOT）分钟数

`0x03FE` 的低 5 位是发射超时分钟数：

```text
3ae62: r0l = @0xFFABBA      ; 0xFFABBA = FRAM[0x03FE] 的 RAM 镜像
3ae68: r0l &= 0x1F
3ae6a: beq  return
3ae6c: @0xFF23AE = r0l      ; 分钟数
3ae72: @0xFF23AC = 0x1770   ; 6000 tick = 1 分钟
3ae7c: bset #2,@0xFF2014
```

`0x3AE0A` 每 6000 tick 递减 `0xFF23AE`；剩余 1 分钟且本分钟计数到 1000（约提前 10 秒）时调用 `0x52A8` 提示，到 0 时调用 `0x52B2` 并置 `0xFF2014.3`。`0x3AE62` 在 TX 入口 `0x3CABE` 被调用。

⇒ **`0x03FE` 低 5 位 = 发射超时（TOT）分钟数，默认 `0x0A`=10 分钟**。高 3 位（`0xE0`，来自 `0x83A4` 表）用途仍未定。

## 9. 实机验证步骤

1. **备份**：`SPR` 读 `0x0000–0x0007`，记录原值（尤其 `FRAM[7]` 的 PWR 位）。
2. **改 TS=2**：`SPW` 写 `0x0006/0x0007`，保持 `FRAM[6]` 与 `FRAM[7]` 高 5 位不变。
3. **断电重启**（不要用 `ZZPE001001;`；它等价于 ALL RESET，会重写 400B 用户设置并应用 JP1006）。
4. **验证**：
   - 调谐到 5.3305 / 5.3515 / 5.3665 / 5.4035，看是否能发射；
   - 看 5 MHz 预设是否变为 UK 7 频道（TS=2）；
   - 用 CAT `ID;` / 状态命令确认机型仍正常；
   - 看 50 MHz 是否被收窄到 50–52、70 MHz 是否出现。
5. **若不能发射**：改 `FRAM[7] |= 0x20`（EXP）再试；仍不行则焊 JP1006，或发 `ZZPE001000;` 进服务模式验证 1.8–75 MHz 表。
6. **回滚**：写回备份的 `FRAM[6]/FRAM[7]`，断电重启。

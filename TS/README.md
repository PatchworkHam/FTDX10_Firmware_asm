# `TS/` — TS 波段方案、5 MHz 发射与最大范围

> 对象：`decoded/firmware/FTDX10_MAIN_V0115.bin`（MAIN V01-15，2024-02-16）。
> 固件代码地址 = **文件偏移**；FRAM 地址写作 `FRAM[...]`；RAM 地址为 H8SX 运行时地址。
> 所有结论都给出可复核地址。本文与脚本**尚未实机验证**。

## 一页结论

| 目标 | 做法 | 实际覆盖 |
|---|---|---|
| 打开 5 MHz 发射 | `FRAM[0x0007]` 的 TS（bit0–2）设为 **2 / 3 / 7** | 频段表出现 60 m 段 |
| 5 MHz 最宽 | **TS=2** | 5.25–5.4065 MHz |
| 5 MHz + 4 m | **TS=2** | 5.25–5.4065 + 70–70.5 |
| HF 各段最宽 + 60 m | **TS=7** | HF 各段放宽（含 5.3515–5.3665）+ 50–54 |
| 宽频（1.8–30 连续 + 5 MHz + 70 m） | **EXP=1**（bit5） | 1.8–30 + 50–54 + 70–70.5 |
| 绝对最大 | **服务模式**（`0xFF2020.7`） | 1.8–75 MHz |

优先级：**服务模式 > EXP > TS**。EXP=1 会整体替换 TS 表。

**TX 门闩（已确认）**：这张表不只是显示/调谐范围，也是 MAIN 侧 TX 许可的输入。TX 状态机 `0x3CC20` → `0x3D0C2` → `0x3D1F2` → `0x32A70` → `0x32A76`；越界（carry clear）清 `0xFFFBA4.2`，在段内（carry set）置位。`0xFF2014.5` 的极性是 **1=在频段内，0=越界**。详见 [`TS频段表与5MHz发射.md`](TS频段表与5MHz发射.md) §7.2。

## 快速用法

```bash
# 离线查看全部 TS 表（不连设备）
python3 TS/yaesu_ts_cat.py --table all

# 只读当前 TS/EXP/PWR 与覆盖
python3 TS/yaesu_ts_cat.py -p /dev/ttyUSB0 --read

# 预览改成 TS=2（默认不写）
python3 TS/yaesu_ts_cat.py -p /dev/ttyUSB0 --ts 2

# 实际写入并回读
python3 TS/yaesu_ts_cat.py -p /dev/ttyUSB0 --ts 2 --apply
```

改完必须**整机断电重启**（不要用 `ZZPE001001;` 代替——它等价于 ALL RESET，会重写 400B 用户设置并应用 JP1006）。

服务模式入口：CAT 发 `ZZPE001000;`（`0xFF2002=0` → 软复位 → `0xFF2020.7=1`，1.8–75 MHz）。**不要用 `ZZPE001001;` 退出**——它走 `0x1446`→`0x1570`→`0x7EA2`→`0x8074`，用默认表重写 400B 用户设置；退出用 RESET 菜单（`0xDCBA` 清 `0xFF2020.7`）或整机断电重启。

服务模式副作用（已确认）：入口 `0x1562` → `0x2680` 用**服务菜单项目编号** `0xFFAB00`（FRAM `0x0344`，0–0x125）索引 `0x27A8` 的 10 B 项目表，并调用 `0xA0C2` **切换当前波段/模式**；改写 RAM `0xFFAAC6`、`0xFF2070/206F/2071/206C`、`0xFFAB23`、`0xFF20B6`（仅 `b0.6=1` 的 70 MHz 项）。`0x2680` 本身不写 FRAM。退出 `0xDCBA` 才保存 371B 内部设置到 `0x000A`、项目号到 `0x0344`、子码到 `0x0346`。进服务模式前至少备份 `FRAM[0x0000..0x0490]`。详见 [`../service_menu/README.md`](../service_menu/README.md)。

# FTDX10 功率修改方案（整理版）

> 目标范围：HF/50M 最高 100 W；70M 仍 50 W、AM 25 W。

> 底层取证过程见 `../hardware/可复现分析过程.md`；
> 短接点（跳线）逐个说明见 `../hardware/短接点功能说明.md`；刷机/回滚见 `../hardware/固件升级.md`。
> **不刷固件、只用 CAT 命令改 FRAM 的目标效果一致方案见 `CAT功率修改方案.md`（方案 CAT）。**
> 所有**固件代码地址** = `decoded/firmware/FTDX10_MAIN_V0115.bin` 的**文件偏移**；FRAM 地址单独以 `FRAM[...]` 标注。

| 项 | 结论 |

## 1. 本机功率限制来源 —— 功率模型全链

### 1.1 功率档来自哪：配置字节的 PWR 位（bit3/4）

配置字节 `0xFF2007` 的 bit3/4 = PWR 档。`and.b #0x18` 这类"掩 2 位字段"的指令全镜像共 **12 处**，
其中**以配置字节 `0xFF2007` 为输入的只有 7 处**（下表）；另外 5 处作用于别的变量
（`0xFFAB2B` 菜单设置打包字节 / `*er1` 设置项步进器 / 状态与遥测路径），**不在功率链上**（分类见 `../hardware/可复现分析过程.md` §5）。7 处为：

| 地址 | 指令 | 所在例程 | 作用 | 影响 |
|---|---|---|---|---|
| `0x150C` | `and.b #0x18,r0h` | `0x1502` | 开机拆分：TS→`0xFF98C7`、PWR→`0xFF98C8`，并置 `0xFF204A.7` | 否（只判有效） |
| `0x1544` | `and.b #0x18,r0h` | `0x153A` | 同上（另一分支） | 否 |
| `0x8112` | `and.b #0x18,r0l` | `0x810C` | FRAM 默认初始化按档写 F/AC | 可选加固 |
| `0x1595C` | `and.b #0x18,r0h` | `0x1594C` | **RF POWER 菜单**区间取档 | **是** |
| `0x159D4` | `and.b #0x18,r0h` | `0x159CC` | **MAX POWER 菜单**区间取档 | **是** |
| `0x3BCA6` | `and.b #0x18,r2l` | `0x3BCA0` | **功率等级钳位**按档取上限 | **是** |

`0xFF2007` 全镜像共被 **46 条指令**引用 = **39 条读入** + **6 条写入**（`0xA30`/`0xA58`/`0x7D22`/`0x7D3E`/`0xDC66`/`0x27F68`）+ **1 条 `btst #5`**（EXP，`0x32B06`）。
**39 条读入中，除了本表 7 处（后续 `and.b #0x18`）、2 处 EXP、4 处 ASCII 帧、3 处配置镜像/FRAM 写、1 处重组、6 处其它以外，剩下 16 处全是 TS 位（后续 `and.b #0x7`）。**
⇒ **没有第二条"取功率档"的路径**。（穷尽性复核：`cmp.b #imm,@0xFF2007` = 0 处；`btst #3/#4,@0xFF2007` = 0 处。）
完整 39 处读者分类表见 `../hardware/可复现分析过程.md` §5.4。

### 1.2 档位 → 菜单能选到多少瓦：表 `0x159F6`

索引函数 `0x1594C`（RF POWER）/ `0x159CC`（MAX POWER）：先取档位索引
`0x18→0`、`0x00→1`、`0x08→2`、其它`→3`，再加频段偏移（HF 0 / 50M 4 / 70M 8 / AM 12），
最后 `shll`（×2）加到基址。
表为 **(min,max) 字节对**，按"组(4) × 档(4)"排列：

| 组 | 含义 | 100W 档 | 50W 档 | 20W 档 | 10W 档 |
|---|---|---|---|---|---|
| 0 | HF | (5,**100**) | (5,50) | (5,10) | (5,10) |
| 1 | 50MHz | (5,**100**) | (5,50) | (5,20) | (5,10) |
| 2 | 70MHz | (5,50) | (5,50) | (5,20) | (5,10) |
| 3 | AM | (5,25) | (5,25) | (5,20) | (5,10) |

⇒ **50W 档的 HF 行上限就是 50**，这就是"50W 机器"的第一个软件闸门。

### 1.3 有效上限：`0x3BBC6 = min(F, AC)`

```
3bbc6: btst #7,@0xff2020 ; bne 0x3bbe2     ; 服务模式 → 直接 50/100/25
3bbd0: jsr @0x3bb3a        ; er1 = &F[子波段]
3bbd4: mov.b @er1,r1l      ; r1l = F
3bbd6: mov.b r1l,r0l       ; r0l = F
3bbd8: jsr @0x3bb6e        ; r0l = min(F, AC[子波段])（返回值在 r0l）
3bbdc: mov.b r0l,r1l
3bbde: mov.b r1l,r0l ; rts ; r0l = min(F, AC)
```

* **F = `0xFFAAF1–F4` ↔ FRAM `0x0335–0x0338`**（HF/50M/70M/AM；由 `0x3BB3A` 依 `0xFF2365` + AM 选择）
* **AC = `0xFFAC26–29` ↔ FRAM `0x046A–0x046D`**（同 4 子波段；由 `0x3BB6E` 选择）
* 两者都在 **FRAM 默认设置块**（FRAM `0x300–0x48F` ↔ RAM `0xFFAABC–0xFFAC4B`）。

### 1.4 F 与 AC 都是**用户可在菜单里改**的值

* 语义：**F = 面板 RF POWER（发射功率设定）**，**AC = MAX POWER（各频段上限）**；
  有效值 = `min(F, AC)`。50W 机通常两者都是 50，要真正到 100 必须两处都推到 100。
* `0x15920`（菜单 ±1 处理，经跳转表 `0x151C2` 生效）：`jsr 0x1594C` 取 `[min,max]` → 按方向 ±1 → `jsr 0x159B4` 写回 RAM 并 `jsr 0xA528` 写回 FRAM `0x335…`。
* `0x20DB4`：MAX POWER 编辑（±1，下界 5）。
* ⇒ **把档位改成 100W 后，用户在菜单里就能把 F、AC 推到 100**；不必改 FRAM 数值。

### 1.5 等级换算与钳位（第二个软件闸门）

`0x3BC26` 取有效值 → `0x3BD7E`（某些标志下强制 10W：`@0xFF2050.5` 或 `@0xFF2023.7`）→ 分级：

| 瓦数 | 等级 r0l | 子级 r0h |
|---|---|---|
| ≥100 | 5 | 0 |
| 50–99 | 4 | W−0x32 |
| 20–49 | 3 | W−0x14 |
| 10–19 | 2 | W−0x0A |
| 5–9 | 1 | W−5 |
| <5 | 0 | W |

`0x3BCA0` 按档钳位等级：100W 档/服务模式 → **不钳**；50W 档 → ≤4；20W 档 → ≤3（子带 <9 时 ≤2，子带 ≥9 时 ≤3）；10W 档 → ≤2。

### 1.6 FRAM 默认块与初始化链（"复位后不会打回"的依据）

* flash `0x82A6` 起的 400 字节块（由 `0x8074` 经 `jsr 0xA5C2` 写进 FRAM `0x300`）里：
  * `0x82A6+0x35 = 0x82DB` → `64 64 32 19` = F 默认 **100/100/50/25**
  * `0x82A6+0x16A = 0x8410` → `64 64 32 19` = AC 默认 **100/100/50/25**
* 随后 `0x810C` 按档位改写 `0x335–338`/`0x46A–46D`（100W:100,100,50,25 / 50W:50,50,50,25 / 20W:10,20,20,20 / 10W:10,10,10,10）。
* 该路径是**活的**：`0x7D44 → 0x7EA6 → 0x7EC2 → 0x8074 → 0x810C`（FRAM `0x0004/5` 的 `A5 5A` 魔数校验失败时走这里）。
* 读短接点的那条（`0x7D2E → 0x7E8E`）是**死的** ⇒ "FRAM 重新初始化"不会让跳线生效。

### 1.7 一句话

> 50W 出不了 100W 是**两个软件闸门**叠加：`0x159F6` 表把菜单上限卡在 50，`0x3BCA0` 把等级钳在 ≤4。
> **方案 M 同时打开这两个闸门**（`0x1595C`/`0x159D4` 开表、`0x3BCA6` 开钳位），并顺手关掉 `0x3BB8A` 的 20W-HF 硬限、加固 `0x8112` 的默认初始化。

## 2. 方案 M（推荐）：5 处单字节掩码补丁（指令各 2 字节）

**原理**：把"取功率档"的**掩码指令**换成"直接给 `0x18`(100W)"，只影响功率逻辑那一行，**完全不碰配置字节**（TS/市场、EXP、AUX 全保留），也不依赖 FRAM 里存的是 `0x00` 还是 `0x18`。

| flash 地址 | 原字节 | 新字节 | 含义 | 作用 |
|---|---|---|---|---|
| `0x08112` | `E8 18` = `and.b #0x18,r0l` | `F8 18` = `mov.b #0x18,r0l` | FRAM 默认初始化按 100W 写 F/AC | 加固 |
| `0x1595C` | `E0 18` = `and.b #0x18,r0h` | `F0 18` = `mov.b #0x18,r0h` | RF POWER 菜单区间取 100W 档 | **必需** |
| `0x159D4` | `E0 18` = `and.b #0x18,r0h` | `F0 18` = `mov.b #0x18,r0h` | MAX POWER 菜单区间取 100W 档 | **必需** |
| `0x3BB8A` | `EE 18` = `and.b #0x18,r6l` | `FE 18` = `mov.b #0x18,r6l` | 取消 20W 档的 HF 10W 硬限 | 20W/10W 机必需；50W 机无副作用 |
| `0x3BCA6` | `EA 18` = `and.b #0x18,r2l` | `FA 18` = `mov.b #0x18,r2l` | 功率等级钳位取 100W 档 | **必需** |

* 全部**同长度**（2 字节）：无需重定位，不改变任何跳转。
* `and.b #imm,Rn` 与 `mov.b #imm,Rn` 都只写目标寄存器 `Rn`（`and.b` 另更新 CCR 的 N/Z/V，`mov.b` 不改 CCR；但 5 个点后面**紧跟** `cmp.b`，CCR 立即被覆盖 ⇒ 实际无差异），而 5 个点的 `Rn` 就是该点**本来就写的那一个寄存器** ⇒ 除"值变成固定 0x18"外无任何新增副作用；后续 `cmp.b #0x18/#0x8/#0x0` 都走"100W / 不钳位"分支。
* **不是**改配置字节，所以市场/TS/EXP/AUX 全不受影响。

## 3. EXP 对照与最小风险

### 3.1 频段规划选择器 `0x32AEE–0x32B2A`

```
32aee: er2 = 0x32B4A            ; 默认（服务）表
32af4: btst #7,@0xff2020 ; bne 0x32B26        ; 服务模式 → 用 0x32B4A
32b00: er2 = 0x32B54            ; EXP 表
32b06: btst #5,@0xff2007 ; bne 0x32B26        ; ★ 全固件唯一消费 EXP 位处
32b10: r2l = @0xff2007 ; and.b #0x7 ; shll.b #2 ; extu.w ; extu.l
32b1e: er2 = @(0x32b2a + er2)   ; 按 TS 选 8 项长字表
32b26: r4 = @er2+ ; rts         ; 返回 段数 / 表指针
```
优先级：**服务模式 ＞ EXP ＞ 按 TS**。即 EXP=1 会**整体替换**掉原本按 TS 选的频段表。

> **这张表也是 MAIN 侧 TX 门闩的输入**：TX 状态机 `0x3CC20` → `0x3D0C2` → `0x3D1F2` → `0x32A70` → `0x32A76` → 本表。
> 越界（carry clear）时 `0x3D0C2` 清 `0xFFFBA4.2`（TX 允许位）；在段内（carry set）置位。
> `0xFF2014.5` 的极性是 **1=在频段内，0=越界**。证据与状态机见 [`../TS/TS频段表与5MHz发射.md`](../TS/TS频段表与5MHz发射.md) §7.2。

### 3.2 三张表

* `0x32B4A`（服务模式，1 段）：`1.8 – 75 MHz`（全开）
* `0x32B54`（**EXP=1**，3 段）：`1.8–30 MHz / 50–54 / 70–70.5 MHz`
* `0x32B2A`（按 TS，8 个长字指针）：`0x32B6E, 0x32BC0, 0x32C12, 0x32C74, 0x32D28, 0x32D7A, 0x32DCC, 0x32CCE`（TS=0…7）
  表 = 各频段方案的业余波段边界；TS=0/1/5/6 内容相同，TS=2/3/7 为频段方案变体：
  - **TS=2**：1.81–2 / 3.5–3.8 / **5.25–5.4065** / 7–7.2 / … / 28–29.7 / 50–52 / **70–70.5**
  - **TS=3**：1.8–2 / 3.5–3.8 / **5.3515–5.3665** / 7–7.2 / … / 50–52
  - **TS=7**：1.8–2 / 3.5–4 / **5.3515–5.3665** / 7–7.5 / 10–10.5 / 14–14.5 / 18–18.5 / 21–21.5 / 24.5–25 / 28–30 / 50–54
  - ⇒ **只有 TS=2/3/7 含 5 MHz**；**只有 TS=2 含 70 MHz**。
  - 逐段边界、5 MHz 预设与 CAT 脚本见 [`../TS/`](../TS/README.md)。

> **服务模式入口（已确认）**：CAT 发 `ZZPE001000;` → `0xFF2002=0` → `jmp 0x6EE` 软复位 → `0x1424`/`0x1438` → `0x1562` 置 `0xFF2020.7`。**不要用 `ZZPE001001;` 退出**：`0xFF2002=1` 走 `0x1446`→`0x1570`→`0x8E50`→`0x7EA2`→`0x8074`，用默认表重写 400B 用户设置并应用 JP1006，等价于 ALL RESET。退出用 RESET 菜单（`0xDCBA` 清 `0xFF2020.7`）或整机断电重启；冷启动（`0x754`）不走这条检查。服务模式还会让 `0x3BBC6`/`0x3BCA0` 走“不钳位”功率路径。

### 3.3 EXP 位的全部消费点

| 地址 | 指令 | 作用 |
|---|---|---|
| `0x32B06` | `btst #5,@0xff2007` | 选频段规划表（§3.1） |
| `0x27F62` | `and.b #0x20,r0l` | 出厂记录重组时**保留** EXP 位 |

（全镜像 `btst #5,@0xff2007` 仅 1 处；`and.b #0x20,r0l` 仅 `0x27F62` 一处。）

### 3.4 EXP 与 PWR 不同：它会被短接点刷新
`0xA38`（活路径）会把配置字节 bit5 换成 **JP1006/EXP 跳线的当前状态**，同时清 bit6。
⇒ 若用"改配置字节"方式（如 `F2 38`）开 EXP，一旦走到 `0xA38`（设置版本不符的迁移路径 `0x13C2 → 0x1570 → 0x8E50 → 0xA38`），bit5 会被跳线状态**覆盖回 0**（跳线不短接时）⇒ 不可靠。

## 4. 刷机 / 回滚 / 砖机

简要流程（完整分场景流程与保底说明见 `../hardware/固件升级.md` §5）：

1. 用 FTDX10 本体格式化 SD 卡；把补丁件**复制并改名**为 `FTDX10_MAIN_V0115.SFL`，放到 **SD 卡的 `FTDX10` 文件夹内**（与 `Capture`/`MemList`/`Menu` 同级）。
2. 菜单 `EXTENSION SETTING → SOFT VERSION` → 勾选 → `UPDATE`；过程**不得断电/拔卡**。
3. 同版本（仍 `V01-15`）会显示 **Ready**，可选可刷。
4. **回滚**：把官方原版 `FTDX10_MAIN_V0115.SFL` 放回同一位置重刷即可 ⇒ 刷前务必留原版。
5. 若刷坏开不了机：内置 **BOOT LOADER** 会显示 `FIRMWARE BOOT ERROR` → 插卡按提示重刷；**只刷 MAIN 不动 DISPLAY**，通常仍可通过该通道恢复；若 DISPLAY/Boot Loader 本身损坏，则无法依靠该通道。

---

## 5. 刷完必做（否则 HF/50M 出不到 100W）

1. 按官方要求做一次 **复位（ALL RESET）**（补丁已保证复位后默认就是 100W 档）。
2. 进菜单把 **RF POWER** 与 **MAX POWER** 都设到 **100**；建议逐子带确认 HF / 50M / 70M / AM。
   * 有效功率 = `min(F, AC)`；两处上限都已放开到 100，但**数值仍要用菜单推上去**。
3. 用功率表实测各波段/模式（SSB、CW、FM、AM、70M）。
   * AM 等模式若仍被 `0x3BD7E` 的逻辑限在 10W，属**功能性限制**（`0xFF2050.5` / `0xFF2023.7`），不是补丁没生效。

## 6. 风险与未决

1. **功率校准/每波段钳位**：`0x3BD16` 用 `0xFFA999/9B`、`0xFFAA2C/2E` 钳制 `0xFF23C7/9`；这些是每波段数据（FRAM 低位区块），未逐项验证 50W 机上是否需同步上调（决定**实际**出多少瓦）。
2. **菜单是否出现 100**：需真机确认（理论：`0x159F6` 组 0/1 的 max=100）。
3. **强制 10W 的标志**：`0x3BD7E` 里的 `0xFF2050.5` / `0xFF2023.7` 具体含义未逐一确认。
4. **版本串**：仍为 `V01-15`；若升级器拒绝同版本，可把 SFL 头 `[FIRM VERSION]` 改为 `V01-16` 重打包（头 CRC32 只覆盖数据段，不改数据段即不影响校验）。

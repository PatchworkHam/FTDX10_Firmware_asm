# FTDX10 隐藏 CAT 命令 —— GUI 工具使用说明

> 配套程序：`cat/ftdx10_hidden_cat_gui.py`
> 命令语义 / 逆向依据：见 `cat/分析过程.md`（取证与逐条逆向）与 `cat/隐藏CAT命令列表.md`（语法与帧格式）；本文档只讲**怎么用**。
> 状态：基于**静态逆向**实现，**未在真机验证**；所有写入操作请先备份、后执行。

---

## 1. 概述

本工具是一个单文件图形程序（Python + tkinter + pyserial），用于读写 FTDX10 MAIN 固件中
**未公开（隐藏）的 CAT 命令**，可完成：

- 11 条有效隐藏命令的**读 / 写**：`VE FD KT EK EO PE SP E0 E8 JP ZZ`；
- **机型 / 魔术串**：机型元数据与 VE / JP / ZZ 魔术串统一保存在
  `cat/rig_profiles.json`；预制 FTDX10 / FT-891，也可“手动输入 / 新建”自定义；
- **功率 / 频段**：读写 PWR 档（100/50/20/10 W）、TS/EXP、各频段 F/AC，并提供
  “临时宽频/服务模式”入口；
- **外部 FRAM 与设置表**读写：外部 FRAM 地址空间 `0x0000–0x7FFF`（`SPW/SPR`）、
  内部设置/校准表 `0xFFA948`（`SPw/SPr`，地址 `0x000A–0x017C`）；
- **完整 FRAM 编辑器**：区域中文说明、十六进制编辑、整片/区间读写、导入导出 `.bin`；
- **服务菜单**：294 项标签/频段/地址/应用目标，按项读写 371B 校准值，`SPN`/`SPAET`；
- **PE 校准**：27 组选择子的原始读取、中文说明和写入；
- **校准文件**读写：371 字节设置表整体读取 / 写回（可选回读校验）、导入导出 `.bin`；
- **完全备份**：把全部可读信息导出为 JSON，并支持从 JSON 恢复可写部分。

程序另提供无界面（命令行）模式，便于脚本化与批量操作。

---

## 2. 安装与启动

```bash
pip install pyserial                     # 串口库
# Debian/Ubuntu 若缺 tkinter：sudo apt install python3-tk
python3 cat/ftdx10_hidden_cat_gui.py     # 启动图形界面
```

无界面模式：

```bash
python3 cat/ftdx10_hidden_cat_gui.py -p /dev/ttyUSB0 -b 38400 --backup out.json
python3 cat/ftdx10_hidden_cat_gui.py -p /dev/ttyUSB0 -b 38400 --restore out.json --yes
```

串口建议：使用 USB 虚拟串口的 **Enhanced COM Port**（或后板 RS-232C），**8N1、无流控**。
菜单 `08 CAT RATE` 默认 9600；做 `E8`(10573B) 或外部 FRAM 转储建议改到 **38400**。

## 3. 界面总览

窗口自上而下分三层：

1. **状态栏**（最上）：左侧显示当前状态（就绪 / 运行中 / 进度），右侧为「取消任务」按钮。
2. **标签页**（中部）：`连接`、`机型 / 魔术串`、`快捷命令`、`功率 / 频段`、
   `FRAM / 表`、`FRAM 全表`、`服务菜单`、`校准 / PE`、`PE 校准`、`完全备份`、`终端`。
3. **日志窗格**（最下）：时间戳记录每一次收发的原始字节，可回查。

## 4. 逐页 · 逐按钮中文功能说明

### 4.1 「连接」页

| 控件 | 功能说明 |
|---|---|
| **端口下拉框** | 列出本机可用串口设备（如 `/dev/ttyUSB0`）。点击展开选择要连接的端口。 |
| **「刷新」按钮** | 重新枚举串口设备并刷新下拉列表。插入新设备后点它。 |
| **波特率下拉框** | 选择通信速率：`4800 / 9600 / 19200 / 38400`，默认 `38400`。必须与设备 `08 CAT RATE` 一致。 |
| **「打开 / 关闭」按钮** | 切换串口开关。未打开时显示「打开」：按所选端口与波特率建立连接，成功后按钮变为「关闭」；再按即断开。 |

> 说明文字：本页下方会提示 CAT 端口类型与帧以 `;` 结束、设备最多缓存 30 帧等信息。

### 4.2 「机型 / 魔术串」页

用于选择/编辑机型预设，并把 VE / JP / ZZ 魔术串应用到当前会话。

| 控件 | 功能说明 |
|---|---|
| **机型预设下拉框** | 从 `cat/rig_profiles.json` 读取 FTDX10 / FT-891 的机型与魔术串；选中后自动填入下方字段。最后一项“自定义（手动输入）”会清空表单。 |
| **「重新载入 JSON」** | 重新读取 `cat/rig_profiles.json`，适合手工编辑文件后刷新。 |
| **「保存当前配置到 JSON」** | 把机型元数据与 VE/JP/ZZ 魔术串一起写回 `rig_profiles.json`（只替换同 id 预设，保留其它预设）。 |
| **「手动输入 / 新建」** | 清空编辑框，允许输入任意机型魔术串；保存时新建 `custom_时间戳` 预设，不覆盖已有项。 |
| **显示名称 / CAT ID** | 预设名称与 `ID;` 返回的机型 ID（DX10 为 `0761`，FT-891 为 `0650`）。 |
| **证据状态** | 合并显示 `status` 与 `magic_status`。FTDX10 两者均为“固件静态确认 / 真机未验证”；FT-891 整体为“魔术串静态确认 / 其它功能未验证”，魔术串为“固件静态确认 / 真机未验证（VE/JP/ZZ）”。 |
| **VE 魔术串** | 7 个 ASCII 字符；FTDX10=`RAH076H`，FT-891=`RAH065H`。也可直接粘贴完整 `VERAH076H` / `VERAH065H`（自动去掉前缀 `VE`）。 |
| **JP 前缀** | 6 个 ASCII 字符；FTDX10=`JP0010`，FT-891=`JP0891`。JP 读取帧就是该前缀，写入帧为前缀 + 8 hex。 |
| **JP 写入值** | 8 个十六进制字符，分成两个 16 位字，必须满足 `v ^ w == 0xFFFF`（例如 `1234EDCB`）；**允许留空**，表示尚未确定。FT-891 的写值未解码，预设为空，需手动填写。JP 回包共 25 字节，固件只允许写前 8 个 hex 字符；其余字节是 `0x2F0×5` 区只读回显。 |
| **ZZ 前缀** | 6 个 ASCII 字符；FTDX10=`PE0010`，FT-891=`PE0891`。也可直接粘贴完整 `ZZPE0010` / `ZZPE0891`（自动去掉前缀 `ZZ`）。服务模式帧为 `ZZ` + 该前缀 + `00`；ALL RESET 为 `01`，不要当普通退出。 |
| **「应用魔术串」** | 校验并把 VE / JP / ZZ 应用到当前 `HiddenCat`；之后相应按钮使用新值。 |
| **「读取 ID」** | 发送 `ID;`，用回包核对当前预设是否匹配实机。 |
| **「读取 VE 版本」/「JP 读取」** | 读取 48 字节版本串 / 25 字节 JP 帧；JP 会解析两个互补字。 |
| **「JP 写入」** | 发送 `JP前缀+8hex`；写启动参数，风险高，需确认。 |

> **JSON 结构**：所有机型数据都在 `rig_profiles.json`。文件顶层保存 `profiles`、
> `fram_regions_zh`、`pe_labels`；每个 profile 包含名称、CAT ID、备注，以及
> `ve_magic`、`ve_full`、`jp_prefix`、`jp_magic`、`zz_prefix`、`magic_status`、
> `magic_evidence`。GUI 保存时整体写回该文件。
>
> **预设说明**：FTDX10 的 `RAH076H` / `JP0010` / `PE0010` 来自本仓库固件逆向；FT-891 的
> `RAH065H` / `JP0891` / `PE0891` 来自 `AH065_M_V0110` 静态比较（VE `0x1D642`、JP `0x19728`、
> ZZ `0x1968A`），**尚未真机验证**。FT-891 的 E0/E8 长度、服务表与功率地址仍与 FTDX10 不同，
> 本 GUI 目前只分离魔术串，其它页面仍按 FTDX10 实现。若实机返回 `?;` 或超时，请按实测值修改并保存。

### 4.3 「快捷命令」页

每个按钮发出一条固定命令，回包显示在下方结果框，同时记入日志。

| 按钮 / 控件 | 发送内容 | 预期回包 | 功能说明 |
|---|---|---|---|
| **「VE 版本查询 (魔术串)」** | `VE<魔术串>;`（默认 `VERAH076H;`） | 48 字节 `VER …` 串 | 读取版本：DSP、ACPU、TFT、SDR 各版本。魔术串在「机型 / 魔术串」页编辑。**只读**。 |
| **「ID 查询」** | `ID;` | 7 字节（如 `ID0761;`） | 读取机型 CAT ID，用于核对机型预设。**只读**。 |
| **FD 通道下拉框** | — | — | 选择 `FD` 的通道号 `0/1/2`。 |
| **「FD 读」** | `FD00<x>;` | 15 字节 | 读取通道 `<x>`（0/1/2）的 32 位频率 / 数据寄存器。**只读**。 |
| **FD 写输入框** | — | — | 输入 8 个十六进制字符（32 位值），如 `1234ABCD`。 |
| **「FD 写 (8 hex)」** | `FD0020<8hex>;` | 通常无回包 | 写入 32 位值到频率寄存器。**写操作**。 |
| **「KT 读余量」** | `KT;` | 6 字节 | 读取 CW 文本（键控存储器）缓冲状态 / 余量。**只读**。 |
| **KT 文本框** | — | — | 输入要写入的 CW 文本（本地按固件范围预检 **ASCII `0x20–0x5F` 或 `0x7D`，最多 30 字符**；字母自动转大写；不能含 `;`，否则会截断帧）。 |
| **「KT 写入文本」** | 先读 `KT` 剩余空间，再发 `KT1<文本>;` | `A;` | 把文本写入 CW 文本缓冲；超出当前剩余空间时本地拒绝。**写操作**。 |
| **「KT 清空 (KT0)」** | `KT0;` | `A;` | 清空 CW 文本缓冲。**写操作**。 |
| **「EK 触发」** | `EK;` | 通常无回包 | 无参触发（调用内部 `0xDA00`）。 |
| **EO 输入框** | — | — | 形如 `0+0000`：`a`(0/1/2) + 符号(`+`/`-`) + `b`(0/1/2) + 三位数值 `ddd`。 |
| **「EO 微调 (a,sign,b,ddd)」** | `EO<a><sign><b><ddd>;` | 通常无回包 | 32 位偏移 / 微调操作。**写操作**。 |
| **「JP 读 (当前前缀)」** | `<JP前缀>;`（FTDX10 默认 `JP0010;`，FT-891 为 `JP0891;`） | 25 字节 | 读取启动 / 服务参数寄存器（DX10 `0xFF2006/07`）。前缀可在「机型 / 魔术串」页改。**只读**。 |
| **JP 输入框** | — | — | 8 个十六进制字符，形如 `1234EDCB`；前 4 位与后 4 位必须**按位互补**（`v ^ w == 0xFFFF`）。 |
| **「JP 写 (互补 8 hex)」** | `<JP前缀><8hex>;` | 通常无回包 | 写入启动参数，需二次确认。**写操作，风险较高**。 |
| **「SPN 写」** | `SP` 帧 `N <hi><lo>` | `A;` | 写服务菜单项目号 N；会切换当前波段/模式，需服务模式。**写操作**。 |
| **「SPSDR 读」** | `SP` 帧 `SDR b0 b1` | 9 字节 | 读取 SDR 相关数据帧。**只读**。 |
| **「E0 取 229B」** | `E0;` | 229 字节 | 取 229 字节诊断帧。**只读**。 |
| **「E8 取 10573B」** | `E8;` | 10573 字节 | 取 10573 字节大转储（低速需十余秒）。**只读**。 |
| **「SPARD 读 371B 表」** | `SP` 帧 `ARD` | 378 字节 | 一次读出 371 字节设置表整帧（需 `0xFF2020` bit7 允许，否则回 `?;`）。**只读**。 |
| **「SPM TR」** | `SP` 帧 `MTR` | 14 字节 | 读取仪表 / 温度类测量值（调用 `0x3B55A`）。**只读**。 |
| **「SPM T2」** | `SP` 帧 `MT2` | 16 字节 | 读取另一组测量值（调用 `0x3B61C`）。**只读**。 |
| **「SPN 读项目号」** | `SP` 帧 `N FF FF` | 7 字节 | 读取服务菜单项目号 `N`（`0xFFAB00`，0–0x125；需门控）。**只读**。写 `N` 会切换当前波段/模式，详见 [`../service_menu/README.md`](../service_menu/README.md)。 |
| **「SPAWE 写使能」** | `SP` 帧 `AWE` | `A;` | 设置表写使能（调用 `0xDCBA`）。**写使能**。 |
| **「SPACL 清除」** | `SP` 帧 `ACL` | `A;` | 清除设置表（调用 `0x7ED0`）；需备份确认和破坏性确认。**破坏性**。 |
| **「SPAET」** | `SP` 帧 `AET` | `A;` | 设置表相关操作（调用 `0x1662`），成功 `A;` 否则 `?;`；有确认框。 |
| **「ZZ 服务模式 (会复位)」** | `ZZ<ZZ前缀>000;`（FTDX10: `ZZPE001000;`；FT-891: `ZZPE089100;`） | 无（设备复位） | 校验 ZZ 前缀后写 `0xFF2002` 并 **`jmp 0x6EE` 软复位**。`00` 进服务模式（`0xFF2020.7=1`），`01` 触发 ALL RESET（`0x1570`→`0x7EA2`→`0x8074` 重写 400B 用户设置）；都会**立即重启设备**，有确认框。 |

> 上方结果框标题行形如 `── VE ──`，下面是回包 hex 与可读文本。
> 写类命令多数**成功时不回包**，此时结果框显示「无」；该行为来自静态逆向，需真机确认（本次未做）。

### 4.4 「功率 / 频段」页

所有写入都是**读-改-写**：只改目标位，保留 TS / PWR / EXP / AUX 的其它位，并在写后回读。

| 控件 | 功能说明 |
|---|---|
| **「读取配置」** | 用 `SPR` 读 `FRAM[0x0006..0x0007]`，解析 `TS(bit0-2)`、`PWR(bit3-4)`、`EXP(bit5)`、`AUX(bit6-7)`。**只读**。 |
| **功率档下拉框** | `100 W=0x18 / 50 W=0x00 / 20 W=0x08 / 10 W=0x10`。 |
| **「预览功率写入」** | 只显示 `FRAM[0x0007]` 的旧值/新值，不写设备。 |
| **「写入功率档」** | 只改 `PWR` 位，保留 TS/EXP/AUX；写后回读。需先勾选备份确认。**写操作**。 |
| **TS 下拉框 / EXP 复选** | TS 选 0–7 对应固件 8 张频段表；EXP 是 bit5，写完后必须整机断电才完全生效。 |
| **「预览 TS/EXP」/「写入 TS/EXP」** | 预览或写入 TS/EXP 位，保留 PWR/AUX。页面会显示目标频率范围（EXP=1 覆盖 TS）。写入需先勾选备份确认。 |
| **各频段 F / AC 输入框** | `F` = RF POWER `FRAM[0x0335..0x0338]`，`AC` = MAX POWER `FRAM[0x046A..0x046D]`，顺序 HF/50M/70M/AM。 |
| **「读取 F/AC」/「写入 F/AC」** | 读取或写入四个频段的功率字节；有效功率 = `min(F, AC)`。读取值显示为 `0xNN`；写入需先勾选备份确认，有确认框和回读。 |
| **「进入服务模式 / 临时宽频（会复位）」** | 发送 `ZZ<ZZ前缀>000;`（DX10 `ZZPE001000;`，FT-891 `ZZPE089100;`），写 `0xFF2002=0` 并软复位；FTDX10 下频段表切到 1.8–75 MHz。**不写 EXP 位**，属于临时宽频。FT-891 的功率/服务表地址不同，尚未适配。 |

> ⚠️ **退出服务模式**：用 RESET 菜单或整机断电；**不要用 `ZZ<前缀>01` 当普通退出**。
> FTDX10 的 `ZZPE001001;` / FT-891 的 `ZZPE089101;` 都是 ALL RESET，会用默认表重写
> 400 字节用户设置并覆盖 EXP。GUI 会按当前 ZZ 前缀生成帧。

### 4.5 「FRAM / 表」页

| 区域 | 控件 | 功能说明 |
|---|---|---|
| **外部 FRAM 地址（SPW/SPR）** | **地址输入框** | 十六进制，范围 `0000–7FFF`（2 字节对齐读写）。 |
| | **数据输入框** | 2 字节十六进制，如 `0000`；写入时的数据，`d0→addr`、`d1→addr+1`。 |
| | **「读 2 字节」** | 用 `SPR` 读该地址的 2 字节，显示 `SPR AAAA -> d0 d1` 及完整回包。**只读**。 |
| | **「写 2 字节」** | 用 `SPW` 写 2 字节到该地址；需先勾选备份确认，有确认框。**写操作**。 |
| **设置/校准表（SPw/SPr）** | **表地址输入框** | 十六进制，范围 `000A–017C`；映射 `0xFFA948+(addr-0x0A)`。 |
| | **数据输入框** | 1 字节十六进制。 |
| | **「读 1 字节」** | 用 `SPr` 读该表地址 1 字节，显示数据与完整回包。**只读**。 |
| | **「写 1 字节」** | 用 `SPw` 写 1 字节到该表地址；需先勾选备份确认，有确认框。**写操作，影响校准**。 |
| | **「读 0xFF2001」** | 用 `SPr` 特殊地址 `0xFFFF` 读取 `0xFF2001`（用于定位特殊单元）。**只读**。 |
| **范围导出** | **起 / 止输入框** | 十六进制地址，默认 `0000`–`00FF`。 |
| | **「导出到文件」** | 用 `SPR` 逐 2 字节把 `[起,止]` 导出为 `.bin` 文件（可选取消）。**只读**。 |

### 4.6 「FRAM 全表」页

真正的整片编辑器：左侧是 `fram/fram_map.csv` 的区域表（中文名来自 `rig_profiles.json`），右侧是可编辑的十六进制文本。

| 控件 | 功能说明 |
|---|---|
| **区域列表** | 显示起止地址、大小、英文名 + 中文说明、置信度；选中会把地址填入起止框。 |
| **起 / 止输入框** | 外部 FRAM 地址，范围 `0000–7FFF`。 |
| **「读取区间」** | 用 `SPR` 逐 2 字节读取，渲染为 `AAAA: 00 11 22 …  ASCII`；任一帧读失败会中止并报错，不会静默填 `0xFF`。**只读**。 |
| **「读取全部 32KB」** | 读取 `0x0000–0x7FFF`；16384 次 `SPR`，耗时较长，可取消。 |
| **「备份 0–0x0490」** | 快速备份最低安全范围 `FRAM[0x0000–0x0490]` 为 `.bin`；写服务菜单/校准前建议先做。 |
| **「我已备份 0–0x0490」** | 写前强制确认；未勾选时本页及其它 FRAM/校准写操作会拒绝执行。 |
| **编辑框** | 只解析形如 `0000: 12 34 56` 的行；行尾 ASCII 注释会被忽略。 |
| **「写入编辑框」** | 按每行地址逐段写回；写入有确认框。若某帧参数/校验含 `0x3B` 会被本地拒绝。 |
| **「导出区间 .bin」** | 把编辑框内容解析后保存为 `.bin`（不访问设备）。 |
| **「导入 .bin 到编辑框」** | 把 `.bin` 按当前“起”地址显示到编辑框，之后可用「写入编辑框」写回。 |

> 写 FRAM 前至少备份 `FRAM[0x0000–0x0490]`。区域中文名只是提示，不能替代逐字节核对。

### 4.7 「服务菜单」页

把 `service_menu/服务菜单项目表.csv` 的 294 项与 371 字节设置表对应起来。

| 控件 | 功能说明 |
|---|---|
| **294 项列表** | 列：`N`、固件 ASCII 标签、频段 MHz、存储 FRAM 地址、应用目标、当前值、新值。 |
| **「读取整表 (SPr 371B)」** | 用 `SPr` 逐字节读 `0x000A–0x017C`，不依赖服务模式门控。**只读**。 |
| **「SPARD 整表」** | 用 `SPARD` 一次读 371B，需要 `0xFF2020.7=1`。**只读**。 |
| **选中项编辑框** | 显示 `N`、标签、频段、存储地址、应用地址、`apply_kind`、当前值、新值。 |
| **「读取选中项」** | 读取当前 N 的 371B 表字节。**只读**。 |
| **「写入选中项校准值」** | 用 `SPw` 写当前 N 的源字节；需先勾选“我已备份 0–0x0490”，可勾选写后 `SPAET`。**写操作，改校准**。 |
| **「SPN 选择/应用 N」** | 发送 `SPN N`；会切换当前波段/模式，需要服务模式。**不是只读**。 |
| **「SPAET 应用特殊项」** | 只对特殊表头/`r3l=1/2` 项成功，普通项回 `?;`；有确认框。 |
| **「SPAWE 写使能」** | 发送 `SPAWE`（内部 `0xDCBA`），写使能并保存服务菜单状态。 |
| **「读取 N/S (0344/0346)」** | 只读 `FRAM[0x0344–0x0345]` 的 16 位大端项目号 `N`（0x000–0x125）与 `FRAM[0x0346]` 子码 `S`（0–7）。 |
| **「SPN 读当前 N」** | `SPN FF FF` 读取 RAM `0xFFAB00` 当前项目号（需服务模式门控）。 |
| **「进入服务模式」** | `ZZ<ZZ前缀>000;`（DX10 `ZZPE001000;`，FT-891 `ZZPE089100;`）入口；会立即软复位。 |

> `r3l=3` 的项目每 3 项共享 1 个应用目标；改 371B 表中的源值不等于直接改共享目标。
> 服务模式退出用 RESET 菜单/断电，**不要**用 `ZZPE001001`。

### 4.8 「校准 / PE」页

| 控件 | 功能说明 |
|---|---|
| **「读取设置表(371B)」** | 用 `SPr` 遍历 `0x000A–0x017C` 读取完整 371 字节设置表，显示在下方文本区。这是**最稳妥**的读取方式（不依赖 `0xFF2020` 门控）。 |
| **「写入设置表(危险)」** | 把文本区当前 371 字节**逐字节**用 `SPw` 写回设备；需勾选「我已备份 0–0x0490」，若勾选「写回后校验」还会回读比对。有确认框。**破坏性写操作**。 |
| **「从备份文件载入…」** | 从 JSON 备份或裸 `.bin` 载入设置表到文本区（载入后可用「写入设置表」写回）。 |
| **「保存为 .bin…」** | 把当前文本区的设置表保存为裸 `.bin` 文件（371 字节）。 |
| **复选「写回后校验」** | 开启后，写回设置表后自动回读逐字节校验。默认开启。 |
| **复选「显示十六进制」** | 开启时按 `地址: 16 字节 hex` 分行显示；关闭时显示为连续 hex 串。 |
| **复选「我已备份 0–0x0490」** | 写设置表/服务菜单前的强制确认；未勾选时写入会被拒绝。 |
| **「读取全部 PE」** | 枚举 `s0,s1,m ∈ {0,1,2}` 共 **27 组** `PE<s0><s1><m>`，逐个读取并列出回包；失败显示 `?;`。末尾统计有效组数。**只读**。 |
| **PE 原始写输入框** | 输入 6 个字符（`PE` 之后的全部参数），用于手动写入 PE。 |
| **PE「发送」** | 发送 `PE<6字符>;`（有确认框）。因 PE 写入会经过查表展开助手（`0x35B76`），**不提供按值自动回写**，仅此原始通道。**写操作，改校准**。 |

### 4.9 「PE 校准」页

| 控件 | 功能说明 |
|---|---|
| **27 组 PE 列表** | 选择子 `s0s1m`（每位 0/1/2），中文说明为“参数组 / 子项 / 模式（原始 PE；位域未完全解码）”。 |
| **「读取全部 PE」** | 逐个读取 27 组，显示原始回包和当前值提示。**只读**。 |
| **「读取选中」** | 读取当前选择子。**只读**。 |
| **选择子 / 符号 / 值** | 写入参数：选择子 3 位，符号 `+`/`-`，值 2 位十六进制；例如 `000+0A`。 |
| **「写入选中」** | 发送 `PE<选择子><符号><2hex>;`；写 PE 校准，需“我已备份 0–0x0490”确认和写入确认。 |

> PE 的选择子/位域尚未完全解码，因此本页**不做自动值换算**，只提供原始读写。写入前先记录回包。

## 5. 典型操作流程

### 5.1 只读巡检（推荐先做）

1. 「连接」页打开串口；
2. 「快捷命令」页依次点 `VE`、`FD 读`、`KT 读余量`、`SPM TR`、`SPARD 读 371B 表`；
3. 「校准 / PE」页点「读取设置表(371B)」——确认能稳定读到 371 字节；
4. 若都正常，说明链路与门控无碍，再考虑备份或写操作。

### 5.2 选择机型 / 输入魔术串

1. 「机型 / 魔术串」页选择 FTDX10 或 FT-891；若机型不在列表，点「手动输入 / 新建」；
2. 点「读取 ID」核对实机 CAT ID（DX10 `0761`，FT-891 `0650`）；
3. 检查 `VE 魔术串` / `JP 前缀` / `ZZ 前缀`；已有实机验证值时可直接覆盖；
4. `JP 写入值` 可留空；要写 JP 时再填入互补的 8 hex；
5. 点「应用魔术串」，再点「读取 VE 版本」或「JP 读取」验证；
6. 需要长期保存时点「保存当前配置到 JSON」：机型与魔术串一起写入 `cat/rig_profiles.json`。

### 5.3 读写功率 / 频段

1. 「功率 / 频段」页点「读取配置」，确认当前 `TS/PWR/EXP`；
2. 只改功率：选功率档 →「预览功率写入」→「写入功率档」（需已勾选备份确认）；
3. 改频段：选 TS / 勾选 EXP →「预览 TS/EXP」→「写入 TS/EXP」（需已勾选备份确认）；
4. 写 TS/EXP 后整机断电重启；若只是想临时到 1.8–75 MHz，用
   「进入服务模式 / 临时宽频（会复位）」，退出用 RESET 菜单或断电；
5. 需要改各频段 RF POWER / MAX POWER 时，在下方 F/AC 区读取、修改、写回（写前先勾选备份确认）。

### 5.4 完全备份

1. 在「完全备份」页勾选需要的项（默认全选）；
2. 如不需要外部 FRAM，取消勾选以节省时间；
3. 点「① 开始完全备份 → JSON」，选择保存路径，等待完成；
4. 备份中 `settings_table` 与（可选）`mem` 是日后恢复的依据，请妥善保存。

### 5.5 从备份恢复

1. 点「② 载入备份并预览」；
2. 需要恢复校准表时点「③ 恢复设置表(危险)」，确认已勾选备份确认并确认后自动写回并校验；
3. 仅当确有必要且能重刷固件时，才点「④ 恢复外部 FRAM(极危险)」（同样要求备份确认，并有两次确认）。

### 5.6 单独改写校准字节

1. 「校准 / PE」页点「读取设置表(371B)」；
2. 到「FRAM / 表」页用「设置/校准表」的「读 1 字节 / 写 1 字节」定位并修改目标字节；
3. 或载入 `.bin` 后在文本区直接编辑，再点「写入设置表(危险)」整体写回。

## 6. 备份 JSON 格式

```jsonc
{
  "format": "ftdx10-hidden-cat-backup",
  "format_version": 1,
  "created": "2026-10-17T12:00:00",
  "transport": { "port": "/dev/ttyUSB0", "baud": 38400 },
  "data": {
    "ve":   { "raw_hex": "…", "text": "VER …" },
    "fd":   { "0": {"raw_hex":"…"}, "1": {…}, "2": {…} },
    "kt":   { "raw_hex": "…" },
    "pe":   { "000": {"raw_hex":"…"}, "001": {"ok": false}, … },
    "settings_table": { "base":"0xFFA948", "start_addr":"0x000A",
                        "end_addr":"0x017C", "bytes":371, "hex":"…" },
    "spard": { "raw_hex":"…", "len":378 },
    "e0":   { "len":229,   "hex":"…" },
    "e8":   { "len":10573, "hex":"…" },
    "jp":   { "raw_hex":"…" },
    "mem":  { "space":"external_fram", "start":"0x0000", "end":"0x7FFF",
              "bytes":32768, "hex":"…" }
  }
}
```

- `format_version: 1` 是 **GUI 备份格式**的版本，与 `power/power_cat_optimized.py` 的功率快照 v3 无关。
- `mem` 为可选（勾选才采集），保存的是 `SPW/SPR` 可访问的**外部 FRAM**，不是内部 RAM；
  `space` 字段用于明确这一点。`settings_table` 才是内部 371 字节设置/校准表。
- 采集失败项写成 `{"error": "…"}` 或 `{"ok": false}`，不影响其余项。

## 7. 无界面（命令行）模式

| 参数 | 说明 |
|---|---|
| `-p, --port` | 串口路径，如 `/dev/ttyUSB0`。 |
| `-b, --baud` | 波特率，默认 `38400`。 |
| `--backup FILE` | 完全备份到 JSON。 |
| `--no-mem` / `--no-fram` | 备份时跳过外部 FRAM。 |
| `--mem-start HEX` / `--mem-end HEX`（别名 `--fram-start` / `--fram-end`） | 外部 FRAM 范围，默认 `0000` / `7FFF`。 |
| `--restore FILE` | 从 JSON 恢复（默认**只**恢复设置表）。 |
| `--restore-mem` / `--restore-fram` | 恢复时**同时**写回外部 FRAM（极危险）。 |
| `--yes` | 跳过交互确认（脚本用）。 |

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 打开串口失败 | 检查端口被其它程序占用、用户是否在 `dialout` 组、设备是否为 Enhanced COM。 |
| 命令无回包 | 写类命令成功时本就不回包；确认波特率与 `08 CAT RATE` 一致。 |
| `SPARD` 回 `?;` | `0xFF2020` bit7 未允许；改用「读取设置表(371B)」（`SPr`）。 |
| `SPr` / `SPw` 回 `?;` | 地址越界（须 `0x000A–0x017C`，特殊读用 `0xFFFF`）；或校验算错。 |
| `SP` 帧被截断 | 参数或校验字节等于 `0x3B`（`;`）会被误判为帧尾，请避开。 |
| 备份很慢 | 外部 FRAM 为 16384 次往返；缩小范围或提高波特率。 |
| 写后设备异常 | 立即停止，用备份恢复设置表；必要时重刷固件。 |

## 9. 安全提示

- `SP`（尤其 `SPA*`、`SPw`）、`PE`、`JP` 会写**校准 / 设置 / 启动参数**，可能导致发射指标
  改变或**无法开机**；`ZZ` 会**立即复位**。
- 程序内所有写操作都有确认对话框；FRAM / 设置表 / 服务菜单 / 校准 / PE 以及功率位、
  各频段 F/AC 写入还要求先勾选「我已备份 0–0x0490」，但**不能替代你自己的判断**。
- 建立链路后**先只读巡检**，再做备份，最后才考虑写操作。
- 本工具与本文档均为**静态逆向**结论，**未在真机验证**；使用风险自负。

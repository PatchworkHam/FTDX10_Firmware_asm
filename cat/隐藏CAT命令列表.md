## 1. 结论与一览
其中影响最大、最值得注意的几条：

| 命令 | 作用（概要） | 风险 |
|---|---|---|
| `SP` | **外部 FRAM / 内部设置表** 读、写（子命令 `SPW/SPR/SPw/SPr/SPM/SPN/SPA/SPS`），`SPARD` 可一次读出 371 字节内部设置表 | **高**（可改校准/配置） |
| `VE` | 版本/ID 查询，需魔术串 `VERAH076H`，回 `R ... DSP/ACPU/TFT/SDR ...;` | 低 |
| `JP` | 服务命令，需 `JP0010...`，读写 `0xFF2006/07` 并搬运 `0x2F0`×5 字节参数区（**不复位**） | 高（改启动/参数区） |
| `ZZ` | 服务模式开关 + 软复位：`ZZPE001000` 进服务模式，`ZZPE001001` 触发 ALL RESET | 高（强制重启；ALL RESET 重写用户设置；服务模式改功率/频段表） |
| `E0` | 发送 229 字节带校验/掩码的诊断数据帧 | 中（只读） |
| `E8` | 发送 10573 字节（`0x294d`）二进制 **内存/数据转储** | 中（只读） |
| `FD` | 读/写一组 32 位频率/数据寄存器，并以 4 字节 BCD 返回 | 中 |
| `KT` | 写入 CW 文本缓冲（≤30 字符），置“文本就绪”标志 | 低 |
| `EK` | 无参数，调用 `0xda00`（与 `KT` 同一子系统） | 低 |
| `PE` | 参数/校准表按子命令读写（`0xffabd1..0xffabe2`），并写总线 | **高**（可改校准） |
| `EO` | 对 32 位偏移寄存器 `0xff20b6` 做 `+/-` 调整（值 < 1000） | 中 |

> 这些命令都能从普通 CAT 串口/USB 口进入：它们和手册命令共用同一张表和同一个解析器，

> 可能改动校准数据或导致设备重启/异常。

## 2. 连接与串口参数

| 项目 | 取值 |
|---|---|
| 端口 | USB 虚拟串口的 **Enhanced COM Port**（CAT 用），或后板 **RS-232C** |
| 波特率 | 菜单 **08 CAT RATE**，出厂默认 **9600**（0=4800 / 1=9600 / 2=19200 / 3=38400）；菜单 06 232C RATE 同理 |
| 帧格式 | 8 数据位、无校验、1 停止位（8N1）、无流控（Yaesu CAT 惯例） |
| 超时 | 菜单 09 CAT TIME OUT TIMER，默认 100 ms |

## 3. 帧格式与解析规则（关键）

- 一帧 = `<2 字母命令><参数...>;`，以 `;`（0x3B）结束；设备按 `;` 切帧。
- 命令表在 `0x27CF2`（126 条 × 2 字节），解析器 `0x27A0A` **只比较前 2 个字符**。
- **参数长度** `r3l` = 2 字母命令之后的字节数，由各处理函数逐一校验（见下）。
- **大小写规则**：接收时默认把英文字母**大写化**；但以 `SP` 或 `EM` 开头的帧**不做大写化**
  （`0x2DB22`/`0x2DB32`/`0x2DC2A`）。
  → 所以 `SPW` 与 `SPw`、`SPR` 与 `SPr` 是**不同**子命令，必须严格区分大小写；
    其余命令（如 `ve`）大小写不敏感。
- **回包**：
  - `A;`（0x41 0x3B）= 成功 ACK（`0x27A5A`）；
  - `?;`（0x3F 0x3B）= 失败 / 参数错（`0x27A5E`）；
  - 数据帧 = `<回显命令><数据><校验?><;>`（逐条见下）；
  - **有个别命令成功时在代码里不回包**（如 `EO`、`EK`、`KT` 写入分支、`PE` 写入分支、
    `FD` 写入分支）；该行为来自静态逆向，需真机确认。
- 队列 / 长度：设备最多缓存 **30** 条帧，单帧拷贝上限 **99 字节**，请勿超长。

## 4. 快速上手代码

```python
import serial, time

def open_cat(port, baud=9600):
    return serial.Serial(port, baud, bytesize=8, parity='N',
                         stopbits=1, timeout=1)

def send_ascii(ser, s: str, wait=0.15):
    """ 发 ASCII 命令；s 不含结尾 ';'，本函数自动补 ';'。"""
    ser.reset_input_buffer()
    ser.write((s + ';').encode('ascii'))
    time.sleep(wait)
    return ser.read(8192)

def send_raw(ser, payload: bytes, wait=0.15):
    """ 发二进制帧（SP 子协议用）；payload 不含结尾 ';'，自动补 ';'。"""
    ser.reset_input_buffer()
    ser.write(payload + b';')
    time.sleep(wait)
    return ser.read(8192)

def echo(ser, s):
    r = send_ascii(ser, s)
    print(f'-> {s!r}   <- {r!r}')
    return r
```

> 用 `repr()` 显示回包，便于观察 `\x00`、`\xff` 等不可见字节。

## 6. 逐条说明

### 6.1 `VE` —— 版本查询（只读）

- **语法**：`VERAH076H`（参数正好 `RAH076H` 7 字节；`0x2D4E8` 逐字节比较）。
- **回包 48 字节**：
  `VER ` + `<机型/日期串 6>` + ` DSP-<cc><dd> ACPU-<ee><ff> TFT-<gg><hh> SDR-<ii><jj>;`
  尖括号为 2 位十六进制（A–F 由 `0x2D7BE` 以 `+7` 生成）。6 字节串取自 ROM `0x3F63E` 或 `0x3F64A`。
- **示例**：
  ```python
  echo(ser, 'VERAH076H')
  # -> 'VERAH076H'
  # <- b'VER 1234AB DSP-0102 ACPU-0304 TFT-0506 SDR-0708;'   (数字以真机为准)
  ```
- 说明：`RAH076H` 是硬编码“口令”，不属于常规 CAT。

### 6.2 `FD` —— 内部寄存器读写

- **读**：`FD00<X>`，`X` ∈ `0`/`1`/`2`（3 参数，`0x29918`）。
  - `X`=0 时按 `0xFF200D` bit6 在 `0xFF2358` / `0xFF22FA` 中选择；
    `X`=1 取 `0xFF98A8`，`X`=2 取 `0xFF98AC`。
  - 回包 **15 字节**：`FD00<X>0<8 hex>;`
  ```python
  echo(ser, 'FD000')     # <- b'FD0000xxxxxxxx;'
  ```
- **写**：`FD0020<8 hex>`（12 参数）。8 个十六进制解成 **4 字节**写入 `0xFF9898..9B`，
  再调用 `0x1454A`；**成功无回包**（`0x29916` `rts`）。
  ```python
  echo(ser, 'FD002000011234')   # <- b''（无回包）
  ```
- 语义推断：内部调试寄存器 / 参数；写路径会置位 `0xFF2019` 相关位。

### 6.3 `KT` —— CW 文本缓冲（键控存储器）

- 缓冲：`0xFF253B`，容量 **30**；`0xFF255A`=已用长度，`0xFF255B`=写指针。
- **读余量**：`KT`（0 参数）。回包 **6 字节**（`0x2A2C4`）：
  `KT` + `<保留字节>` + `<2 hex 剩余空间>` + `;`
  （第 3 字节是缓冲里的陈旧字节，属固件小瑕疵，可忽略）。
- **清空**：`KT0`（1 参数）。若 `0xFF203D` bit0 已置则置 bit1；**无回包**。
- **追加文本**：`KT1<文本>`（≥2 参数，文本长度 = `r3l-1`）。追加后总长 ≤ 30；
  固件在 `0x2A224` 按自己的范围校验字符（静态看为 `0x20–0x5F` 或 `0x7D`；CAT 默认
  会把字母大写化，所以小写字母通常以大写形式通过）。非法字符回 `?;`；成功无回包，
  `0x2A288` 置 `0xFF203D` bit0。注意 `0x3B`（`;`）虽在固件允许集合内，但它是 CAT 帧尾，
  实际不能出现在文本中；GUI 会在本地拒绝。
  ```python
  echo(ser, 'KT')              # <- b'KT\x00..\x1e;'   （剩余=30=0x1E）
  echo(ser, 'KT1HELLO WORLD')  # <- b''（无回包）
  echo(ser, 'KT0')             # <- b''（清空）
  ```

### 6.4 `EK` —— 无参触发

- **语法**：`EK`（参数长度必须为 0；`0x292A6`）。
- 行为：调用 `0xDA00`（与 `KT` 同属 `0xFF203D` 子系统）；**无回包**。
  ```python
  echo(ser, 'EK')   # <- b''
  ```

### 6.5 `EO` —— 偏移 / 微调

- **语法**：`EO<a><sign><b><ddd>`（**6 参数**，`0x29484`）：
  - `a` ∈ `0`/`1`/`2`：作用对象（0→`0xA790` 路径，1→`0xA79C` 路径，2→两者）；
  - `sign` = `+` 或 `-`：加 / 减；
  - `b` ∈ `0`/`1`/`2`：步进标度（×1 / ×1000 / ×1000000）；
  - `ddd` = 3 位十进制 `000`–`999`。
- 结果累加到 32 位单元 `0xFF20B6`，并置 `0xFF2013` bit4。成功**无回包**，非法回 `?;`。
  ```python
  echo(ser, 'EO0+0123')   # <- b''（对象0，+，×1，123）
  echo(ser, 'EO2-0010')   # <- b''（对象2，-，×1，10）
  ```

### 6.6 `PE` —— 校准 / 参数字节读写

- **读**：`PE<3 选择位>`（3 参数，`0x2B842`），如 `PE000`。三元组 (s0,s1,mode) 各取 `0/1/2`，
  映射到 18 字节范围 `0xFFABD1..0xFFABE2`。
  - 回包 **9 字节**：`PE<s0><s1><m><sign><2 hex>;`，`sign` ∈ {`0`,`+`,`-`}（负数以补码读取）。
  ```python
  echo(ser, 'PE000')   # <- b'PE000+0A;'（示例）
  echo(ser, 'PE100')
  echo(ser, 'PE200')
  ```
- **写**：`PE<s0><s1><m><sym><2 hex>`（6 参数，`0x2B580`）。写同区并置 `0xFF2029` bit4；
  **成功无回包**。
  ```python
  echo(ser, 'PE000+0A')   # <- b''
  ```
- 说明：`PE` 直接读写**校准 / 调整参数**，误写会影响机器指标。

### 6.7 `E0` / `E8` —— 内部二进制取数

- `E0`（`0x2D7C6`）：发送 **229（0xE5）字节**的掩码 / 校验帧（源基址 `0xFF2397`）。
- `E8`（`0x2D8D6`）：发送 **10573（0x294D）字节**（源 `0xFF36E2` → 目标 `0xFF6089`）。
- 两条**不校验参数**；回包是**二进制**（不是 ASCII），需按长度读取。
  ```python
  r = send_ascii(ser, 'E8'); print(len(r))   # ~10573
  ```

### 6.8 `JP` —— 启动 / 参数区读写

- **读**：`JP0010`（4 参数）→ 回 **25 字节**（`r0=0x19`）：`JP0010` + 8 hex（`0xFF2006/07` 及其按位取反）
  + 8 hex + 2 hex（`0xA4E2` 读回的 `0x2F0`×5 区前 5 字节）+ `;`。
- **写**：`JP0010<8 hex>`（12 参数）。8 个十六进制分成两个 16 位字 v 与 w，
  **必须满足 `v ^ w == 0xFFFF`**（即 w 是 v 的按位取反，`0x27F3A`）；随后写
  `0xFF2006`/`0xFF2007` 并搬运 `0x2F0`×5 字节（`0xA5C2`）。**成功无回包**。
  ```python
  echo(ser, 'JP0010')             # 读
  echo(ser, 'JP00101234EDCB')     # 写 v=0x1234, w=0xEDCB (互补)
  ```
- ⚠️ 涉及启动参数 / 内部搬运，误用可能无法开机。

### 6.9 `ZZ` —— 服务模式开关 / 复位

- **语法**：`ZZPE0010<2 dec>`（8 参数，`0x27DEE`）；`<2 dec>` 必须是十进制 `00` 或 `01`（`0x282A6` 只接受 `'0'`–`'9'`，`0x35B72` 做 BCD→二进制，结果必须 `< 2`）。
- 写 `0xFF2002` 后 `jmp 0x6EE`（软复位，栈设 `0xFFC000`）。**立即重启，无回包**。
  ```python
  send_ascii(ser, 'ZZPE001000')   # 0xFF2002=0 → 服务模式（0xFF2020.7=1）
  send_ascii(ser, 'ZZPE001001')   # 0xFF2002=1 → ALL RESET（重写 400B 用户设置）
  ```
- 服务模式会启用 `SPN`/`SPA*` 门控、把频段表切到 `0x32B4A`（1.8–75 MHz）、并改变功率钳位；退出用 RESET 菜单（`0xDCBA` 清 `0xFF2020.7`）或整机断电。
- **入口副作用**：`0x1562` → `0x2680` 用**服务菜单项目编号** `0xFFAB00`（FRAM `0x0344`，0–0x125）索引 `0x27A8` 的 10 字节项目描述表，改写 RAM `0xFFAAC6`（当前波段号）、`0xFF2070/206F/2071/206C`、`0xFFAB23`、`0xFF20B6`（项目对应频段频率）；并调用 `0xA0C2` **切换当前波段/模式**。`0x2680` 本身不写 FRAM。详见 [`../service_menu/README.md`](../service_menu/README.md)。
- **退出保存**：`0xDCBA` 把 371 B 内部设置 `0xFFA948` 写入 `FRAM[0x000A]`、项目号 `0xFFAB00` 写入 `0x0344`、子码 `0xFFAB02` 写入 `0x0346`，并清 `0xFF2020.7`；**不保存** 400 B 用户设置块。进服务模式前至少备份 `FRAM[0x0000..0x0490]`。
- ⚠️ **不要用 `ZZPE001001;` 退出服务模式**：它走 `0x1446`→`0x1570`→`0x8E50`→`0x7EA2`→`0x8074`，用默认表 `0x82A6` 重写 `FRAM[0x0300]` 的 400B 用户设置，并用 JP1006 覆盖 EXP，等价于 ALL RESET。冷启动（`0x754`）不执行该检查。

## 7. `SP` 二进制子协议（重点）

`SP` 是**二进制**子协议：`SP` 之后的字节按**原始二进制**解释（**不是** ASCII 十六进制），
校验和 = **原始字节之和 & 0xFF**，作为一个**原始字节**发送。因 `SP` 帧不做大写化，子命令区分大小写。

**帧布局**：`'S' 'P' <子命令字节/参数...> <校验字节>`，最后跟 `;`。
（校验字节 = `('S'+'P'+其后所有字节) & 0xFF`）

> ⚠️ 二进制校验字节**可能等于 `0x3B`（`;`）**而被设备当作帧尾；参数里也应避免出现 `0x3B`。
> 若遇到异常，请更换参数，必要时再做真机确认。

子命令（首字节 = `0xFF8A32`，`0x2CF86` 分派）：

| 子命令 | 语法（除首字节外均为原始字节） | 参数长度 | 回包 |
|---|---|---|---|
| `W` | `SPW <addrHi> <addrLo> <d0> <d1> <chk>` | 6 | `A;` |
| `R` | `SPR <addrHi> <addrLo> <chk>` | 4 | `SPR<addrHi><addrLo><d0><d1><chk>;`（9B） |
| `w` | `SPw <addrHi> <addrLo> <pad> <data> <chk>` | 6 | `A;` |
| `r` | `SPr <addrHi> <addrLo> <chk>` | 4 | `SPr<addrHi><addrLo><00><data><chk>;`（9B） |
| `M` | `SPMTR <chk>` 或 `SPMT2 <chk>` | 4 | 14B / 16B 帧（数据 12B / 14B） |
| `N` | `SPN <hi> <lo> <chk>`（写）；读时 `<hi><lo>` = `FF FF` | 4 | 写：`A;`；读：`SPN<hi><lo><chk>;`（7B） |
| `A` | `SPAWE` / `SPARD` / `SPACL` / `SPAET` `<chk>` | 4 | 见下 |
| `S` | `SPSDR <b0> <b1> <chk>` | 6 | 9B 数据帧 |

> **门控**：`SPN` 与 `SPA*` 需要 `0xFF2020` bit7 = 1（扩展/维修模式），否则一律回 `?;`；
> `SPW` / `SPR` / `SPw` / `SPr` / `SPM` / `SPSDR` **无**此门控。

逐条：

- **SPW**（写外部 FRAM `0x0000–0x7FFF` 的 2 字节）：`addr=(addrHi<<8)|addrLo` 必须 `< 0x8000`。
  d0→addr、d1→addr+1（写原语 `0xA528` 会自动 `addr++`）。
  校验 = `('S'+'P'+'W'+addrHi+addrLo+d0+d1) & 0xFF`。
  例：写 0x0123 = 0x45,0x67 → 字节 `53 50 57 01 23 45 67 CA`，再跟 `;`。
- **SPR**（读 2 字节）：addr 必须 `< 0x8000`。回包回显请求前 5 字节后接 `d0 d1 chk ;`。
  例：读 0x0100 → 发送 `53 50 52 01 00 F6` + `;`。
- **SPw**（写设置表）：`addr` ∈ `0x000A–0x017C`，写入 `0xFFA948 + (addr-0x0A)`；
  校验 = `('S'+'P'+'w'+addrHi+addrLo+pad+data)&0xFF`（`pad` 参与校验但不使用）。
- **SPr**（读设置表）：`addr`=`0xFFFF`→读 `0xFF2001`；`0x000A–0x017C`→读设置表。
  回包含一个 `0x00` 保留字节（原校验位被清零）。
- **SPM**：`SPMTR`→14 字节；`SPMT2`→16 字节（调用 `0x3B55A` / `0x3B61C` 取读数）。
  校验 = 前 5 字节之和。
- **SPN**（**需 `0xFF2020` bit7 = 1**，否则回 `?;`）：把 `<hi>:<lo>` 当作 16 位数：`0xFFFF`=读 `0xFFAB00`；
  `< 0x0126`=写 `0xFFAB00` 并调用 `0x1622`（`0x1622` → `0x2680`）；其它值回 `?;`。
  `0xFFAB00` 是**服务菜单项目编号** `N`（0–0x125，FRAM `0x0344`）；
  `0x2680` 用 `N*10` 索引 `0x27A8` 的 10 字节项目描述表，并调用 `0xA0C2` **切换当前波段/模式**。
  它改写 RAM `0xFFAAC6`（当前波段号）、`0xFF2070/206F/2071/206C`、`0xFFAB23`；`0xFF20B6` 仅在 `b0.6=1` 时写入（当前表只有 70 MHz 项，值 70.25 MHz）。
  这些是 RAM 改写；退出服务模式（或 `SPAWE` → `0xDCBA`）时才把 `N` 写入 FRAM `0x0344`、子码 `0xFFAB02` 写入 `0x0346`。
  并行标签表在 `0x3324`（294 × 25 B）：`N=0x110–0x11A` 是 `FB GAIN 1.8…70`，`0x11B–0x125` 是 `CART LIMIT 1.8…70`。
  **结论**：`SPN` 不能代替 TS/EXP 来开 5 MHz 发射（它不写 `FRAM[0x0007]`，也不改 TX 频段表 `0x32B2A`）；
  它会改变当前波段/模式，不应把它当成只读操作。详见 [`../service_menu/README.md`](../service_menu/README.md)。
- **SPA**（**需 `0xFF2020` bit7 = 1**，否则回 `?;`）：
  - `SPAWE` → 调用 `0xDCBA`（写使能），回 `A;`
  - `SPARD` → 回 **378（0x17A）字节**：回显 5 字节 + 371 字节设置表 `0xFFA948` + 校验 + `;`
    （`0x2D2D2`，经 `0xFF6089` 缓冲发送）
  - `SPACL` → 清（`0x7ED0`），回 `A;`
  - `SPAET` → 调用 `0x1662`，成功回 `A;` 否则 `?;`（仅 `0x1662` 支持的表头/`r3l=1/2` 特殊项会成功；普通项回 `?;`）
- **SPSDR**：`<b0>:<b1>` 组成字，调用 `0x3E34E` 并轮询 `0xFF2056` bit1，返回 9 字节
  （`SPSDR` + 2 数据字节 + 校验 + `;`）。校验 = 前 7 字节之和。
  （固件里对 `D` 的检查是死代码，实际只强制第 3 字节为 `R`。）

**Python 参考（发送 SP 帧）**：

```python
def sp_frame(body: bytes) -> bytes:
    """ body 不含 'S''P'；自动计算原始字节校验并补 ';'。"""
    head = b'SP' + body
    chk  = sum(head) & 0xFF
    return head + bytes([chk]) + b';'

# SPW: 写 0x0123 = 0x45, 0x67
print(send_raw(ser, sp_frame(b'W\x01\x23\x45\x67')))   # -> b'A;'

# SPR: 读 0x0100
print(send_raw(ser, sp_frame(b'R\x01\x00')).hex())     # 5350520100 <d0 d1> <chk> 3b

# SPr: 读设置表 0x0A（地址为大端：hi=0x00, lo=0x0A）
print(send_raw(ser, sp_frame(b'r\x00\x0a')).hex())     # 535072000a 1f 3b（回包含 0x00 保留位）

# SPN: 读当前服务菜单项目号 N（0xFFAB00；hi=lo=FF）
print(send_raw(ser, sp_frame(b'N\xff\xff')).hex())     # 53504e <hi lo> <chk> 3b

# SPARD: 导出设置表（需 0xFF2020 bit7 允许，否则 b'?;'）
print(len(send_raw(ser, sp_frame(b'ARD'))))            # 378
```

## 8. 安全与风险（务必阅读）

- **写类**：`SP`（尤其 `SPA*`、`SPw`）、`PE`、`JP` 会写**校准 / 设置 / 启动参数**，
  可能导致发射指标改变或**无法开机**。`ZZ` 会**立即复位**。
- **建议顺序**：
  1. 先用**只读**命令验证链路：`VE`、`FD00x`、`KT`、`PE000/100/200`、`E0`、`E8`、
     `SPR` / `SPr` / `SPARD`（读）。
  2. 写类命令仅在**能重刷固件、且理解后果**时使用。
  3. 操作前备份固件文件与原始设置。
- **二进制帧注意**：`SP` 校验字节或参数若等于 `0x3B` 会被误判为帧尾。
- **免责**：本节为**静态逆向**结论，**未在真机验证**；请自行评估风险。
